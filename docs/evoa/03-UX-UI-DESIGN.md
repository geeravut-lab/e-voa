## 1. แนวคิด: "Sunny Gateway"

ลูกค้าต้องรู้สึก 2 อย่างพร้อมกัน

| ความรู้สึก | ทำไม | ออกแบบอย่างไร |
| --- | --- | --- |
| **ปลอดภัย เชื่อถือได้** | กำลังส่งพาสปอร์ต รูปหน้า และเงิน ให้ระบบที่ต่อกับด่านตรวจคนเข้าเมือง | น้ำเงินเข้ม (Navy Trust) เป็นสีตัวอักษร, เลย์เอาต์เป็นระเบียบ, บอกราคาครบก่อนเริ่ม, ข้อความ "ส่งตรงถึง สตม. · เข้ารหัส" |
| **สดใส อยากมาเที่ยว** | ทริปกำลังจะเริ่ม — ความรู้สึกแรกต่อประเทศไทย | ฟ้าทะเลอันดามัน + เหลืองทองแดด บนพื้นสีทรายอุ่น, ภาพประกอบแนวพระอาทิตย์-ทะเล-ยอดวัด, คำพูดเป็นมิตร |

คำสำคัญ: **Trustworthy · Sunny & joyful · Effortless · Global (ไม่ไทยจ๋าจนชาติอื่นรู้สึกไม่ใช่ของตัวเอง) · Mobile-first**

สิ่งที่ **ไม่** ทำ:
- ไม่ใช้ตราครุฑ ตรา สตม. หรือสีธงชาติเป็นสีหลัก — แพลตฟอร์มเป็นผู้ให้บริการ ต้องไม่ดูเหมือนเว็บไซต์ราชการเอง (กันความสับสนและปัญหาข้อกฎหมาย) แต่ระบุสถานะ "ผู้ให้บริการที่ได้รับอนุญาต" ให้ชัด
- ไม่ใช้ลายไทยหนาแน่น/สีทองแดงแบบเว็บโรงแรมหรู — ทำให้ดูช้าและเป็นทางการเกินไป
- ไม่ใช้ dark pattern ในการขายบริการเสริม

## 2. โลโก้และ Favicon

| ไฟล์ | ใช้ที่ไหน |
| --- | --- |
| `brand/logo-horizontal.svg` | โลโก้หลัก — header เว็บ, อีเมล, เอกสาร PDF |
| `brand/logo-horizontal-on-dark.svg` | บนพื้นเข้ม (footer, หลังบ้าน) |
| `brand/logo-stacked.svg` | พื้นที่สี่เหลี่ยม (โปสเตอร์, splash) |
| `brand/logo-mark.svg` | สัญลักษณ์เดี่ยว, avatar, ไอคอนแอป |
| `brand/favicon.svg`, `favicon.ico` (16/32/48), `favicon-16/32/48.png` | แท็บเบราว์เซอร์ (เวอร์ชันเส้นหนา ตัดจุดทอง ให้อ่านออกที่ 16 px) |
| `brand/apple-touch-icon.png` (180) | ไอคอนบนหน้าจอ iPhone |
| `brand/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | PWA manifest (Android) |
| `brand/og-image.png` (1200×630) | การ์ดตอนแชร์ลิงก์ (LINE, WhatsApp, Facebook, X) |

ความหมายของสัญลักษณ์: **ซุ้มประตูทรงยอดแหลม** (กลิ่นอายซุ้มประตูวัดไทย + แนวคิด "Seamless Gateway") + **เครื่องหมายถูกสีทอง** (อนุมัติแล้ว) + **จุดทองบนยอด** (พระอาทิตย์/ยอดฉัตร) บนพื้นไล่สี teal → น้ำเงิน; คำว่า E‑VOA ใช้ขีดกลางสีทอง
ตัวอักษรในไฟล์โลโก้ถูกแปลงเป็นเส้น (path) แล้ว — แสดงผลเหมือนกันทุกเครื่องโดยไม่ต้องมีฟอนต์

กฎการใช้: พื้นที่ว่างรอบโลโก้ ≥ ครึ่งหนึ่งของความสูงสัญลักษณ์ · ขนาดเล็กสุดของโลโก้แนวนอน 120 px กว้าง · ห้ามเปลี่ยนสี ยืด หมุน หรือใส่เงา

ติดตั้งใน Next.js (App Router): คัดลอก `favicon.ico` → `app/favicon.ico`, `favicon.svg` → `app/icon.svg`, `apple-touch-icon.png` → `app/apple-icon.png`, `og-image.png` → `app/opengraph-image.png`, ไอคอน PWA → `public/` และอ้างใน `app/manifest.ts` (`theme_color: #1557E0`, `background_color: #FBFAF6`)

## 5. รูปทรง ระยะ ไอคอน ภาพ และการเคลื่อนไหว

- **มุมโค้ง**: การ์ด 20 px · ปุ่ม/ช่องกรอก 14 px · ป้ายสถานะเต็มมน · ไอคอนแอป 16/64
- **ระยะ**: ฐาน 4 px (4 · 8 · 12 · 16 · 24 · 32 · 48 · 64)
- **เป้าแตะ** ≥ 44 px · focus ring 3 px สี `primary` · ปุ่มหลักสูง 48 px บนมือถือ
- **ไอคอน**: เส้น 2 px ปลายมน (ชุด Lucide หรือเทียบเท่า) — ไม่ใช้ emoji เป็นไอคอน
- **ภาพประกอบ**: flat/เวกเตอร์ โทนพระอาทิตย์–ทะเล–ยอดวัด–เครื่องบิน, ตัวละครหลากหลายเชื้อชาติ (อินเดีย จีน ตะวันออกกลาง ยุโรปตะวันออก ฯลฯ) — ให้ทุกชาติเห็นตัวเองในภาพ
- **รูปถ่าย**: แสงธรรมชาติ ทะเล/เมือง/สนามบินสุวรรณภูมิ — หลีกเลี่ยงภาพคิวยาว ยกเว้นตอนเปรียบเทียบ "ก่อน/หลัง"
- **Motion**: 150–250 ms ease-out · ช่วงสำคัญมีโมเมนต์เดียว = **ตอนอนุมัติ** (เครื่องหมายถูกสีทองวาดเส้น + confetti เบา ๆ) · เคารพ `prefers-reduced-motion`

## 8. น้ำเสียงของข้อความ (Voice & tone)

- สั้น ตรง เป็นมิตร ใช้ "you" — "We'll email you when it's approved" ไม่ใช่ "Notification will be dispatched"
- ปุ่มบอกสิ่งที่จะเกิด: "Pay THB 6,578", "Retake photo", "Send to Immigration"
- ข้อผิดพลาด = เกิดอะไร + แก้อย่างไร: "This photo is blurry. Use daylight and look straight at the camera."
- ไม่ใช้ศัพท์ระบบ (docket, webReferenceNumber) กับลูกค้า — ใช้ "application number"
- คำแปลทุกภาษาให้เจ้าของภาษาตรวจ โดยเฉพาะข้อความทางกฎหมาย/คืนเงิน

## 9. Accessibility & หลายภาษา

- WCAG 2.2 AA · ทุกฟอร์มมี label · error ผูก `aria-describedby` · สถานะมีไอคอน + ข้อความ ไม่ใช้สีอย่างเดียว
- กล้อง/สแกน ต้องมีทางเลือก "อัปโหลดไฟล์" และ "กรอกเอง" เสมอ
- ภาษาเริ่มจาก `Accept-Language` + สลับได้ทุกหน้า, จำค่าไว้, URL มี locale (`/en`, `/zh-CN`, `/ar`)
- วันที่แสดงแบบไม่กำกวม (`14 Dec 2026`) ไม่ใช้ `12/14` · สกุลเงิน THB พร้อมค่าประมาณสกุลท้องถิ่น
