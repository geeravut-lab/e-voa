Design concept · “Sunny Gateway”

ประตูสู่เมืองไทยที่สดใส อุ่นใจ และผ่านได้ในไม่กี่นาที

นักท่องเที่ยวต้องรู้สึกสองอย่างพร้อมกัน: “ปลอดภัย เชื่อถือได้” เพราะกำลังส่งข้อมูลพาสปอร์ตให้ด่านตรวจคนเข้าเมือง และ “ตื่นเต้น อยากมาเที่ยว” เพราะทริปกำลังจะเริ่ม ชุดสีจึงจับคู่ น้ำเงินเข้มที่หนักแน่น (ความน่าเชื่อถือ) กับ ฟ้าทะเลอันดามัน + เหลืองทองแดดเมืองไทย (ความสดใส) บนพื้นสีทรายอุ่น ๆ

1 · โลโก้ & Favicon

“ซุ้มประตู + เครื่องหมายถูก” = ผ่านด่านได้แล้ว

สัญลักษณ์คือ ซุ้มประตูทรงยอดแหลม (ได้กลิ่นอายซุ้มประตูวัดไทยและแนวคิด “Seamless Gateway” ใน proposal) มี เครื่องหมายถูกสีทอง อยู่ข้างใน = อนุมัติแล้ว และ จุดทองที่ยอด แทนพระอาทิตย์/ยอดฉัตร พื้นไล่สีจากฟ้าทะเล (teal) ไปน้ำเงิน ตัวอักษร “E-VOA” ใช้ขีดกลางสีทองเชื่อมคำ ไม่ใช้ตราครุฑหรือตรา สตม. เพื่อไม่ให้ดูเป็นเว็บของรัฐบาลเอง

รูปทรง & ระยะ

  • มุมโค้ง: การ์ด 20px · ปุ่ม/ช่องกรอก 14px · ป้ายสถานะเต็มมน
  • ระยะห่างฐาน 4px (4·8·12·16·24·32·48)
  • เป้าแตะ ≥ 44px · ช่องกรอก 16px · focus ring 3px สีน้ำเงิน
  • เงาสีน้ำเงินเข้มโปร่ง ไม่ใช่ดำล้วน · ใช้กับการ์ดที่ “ลอย” เท่านั้น

หลัก UX ที่ห้ามละเมิด

  • ราคาเห็นก่อนกรอก ไม่มีค่าธรรมเนียมแอบโผล่ตอนจ่าย
  • บริการเสริมเป็น opt-in ไม่ติ๊กไว้ให้ ไม่ใช้ dark pattern
  • บันทึกอัตโนมัติทุกช่อง ปิดแอปแล้วกลับมาทำต่อได้
  • สถานะไม่สื่อด้วยสีอย่างเดียว มีไอคอน + ข้อความเสมอ
  • ข้อผิดพลาดบอกวิธีแก้ เป็นภาษาของผู้ใช้
