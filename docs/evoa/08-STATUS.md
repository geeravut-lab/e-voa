## สิ่งที่ต้องการให้คุณทำ/ตัดสินใจ (ไม่ใช่งานเขียนโค้ด)
1. **Vercel env** (ตอนนี้ทำให้ Google/LINE ใช้ไม่ได้): `SUPABASE_SERVICE_ROLE_KEY`, `DATA_ENCRYPTION_KEY`, `CRON_SECRET`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` → Redeploy → เปิด `/api/health` ต้องเห็น `"ok": true`
2. ลงทะเบียน webhook ใน Stripe และลองจ่ายด้วยบัตรทดสอบหนึ่งครั้ง
3. ตั้ง SMTP (Resend) เพื่อให้ "ลืมรหัสผ่าน" และอีเมลแจ้งสถานะทำงาน
4. ใส่รายชื่อประเทศ VOA / ยกเว้นวีซ่า ที่ `/admin/eligibility` (ต้องมาจากประกาศทางการ)
5. ขอสเปก/credential จริงจาก สตม. และพาร์ตเนอร์ (และยืนยันวิธีเซ็น request ของพาร์ตเนอร์)
6. แจ้งอีเมลที่คุณใช้ login เพื่อให้ผมตั้งเป็นเจ้าของระบบ

## รอบ Phase 4 (ที่เพิ่งทำเสร็จ)
- **รูปถ่ายใบหน้า:** ตรวจหน้า/พื้นหลังในเบราว์เซอร์ · **ถ่าย selfie ด้วยกล้องได้** (มีกรอบวงรี, ถ่ายใหม่ได้, ถ้าเปิดกล้องไม่ได้จะบอกวิธีแก้หรือใช้กล้องของเครื่อง) · **ปุ่ม "ดูไฟล์"** ทุกไฟล์ที่อัปโหลด (รูปเปิดเป็นหน้าต่างขยาย, PDF เปิดแท็บใหม่; ดูได้เฉพาะเจ้าของและเจ้าหน้าที่) และรายการเอกสารที่อัปโหลดในหน้ารายละเอียดใบสมัคร
- **SEO:** hreflang + บทความ · **ใบกำกับภาษี** PDF ภาษาไทย · **รายละเอียดสนามบิน** แก้ได้ที่ `/admin/airports`
- **AI assistant** `/help/chat` · **LINE/WhatsApp** `/account/notifications`, `/admin/messaging` · **Agency** `/agency`, `/admin/agencies` · **Partner** `/partner`, `/admin/partners`
- **แก้บั๊กที่พบระหว่างทดสอบ:** ช่องกรอกในหน้าฝั่งเซิร์ฟเวอร์ (เช่น หน้าเช็คสถานะ) เสียสไตล์เพราะค่าคงที่ `inputCls` ถูก export จากไฟล์ client — ย้ายไป `src/components/inputStyles.ts` แล้ว
- **ยังไม่ได้ลองกับของจริง:** Claude API, LINE, WhatsApp, Resend, AeroDataBox (ไม่มี key) · ข้อความกฎหมายภาษาไทย/จีนและการจัดการใบกำกับภาษีควรให้ผู้เชี่ยวชาญตรวจ
- **ข้อควรทราบ partner portal:** พาร์ตเนอร์ที่ไม่มี API ออกโค้ดบัตรกำนัลในระบบเรา (ไม่ได้เรียกระบบภายนอก); การจ่ายเงินให้พาร์ตเนอร์เป็นการ "บันทึกว่าจ่ายแล้ว" โดยเจ้าหน้าที่ ระบบไม่โอนเงินเอง
- **เมนูและการแจ้งเตือน:** เปลี่ยนภาษาเป็น drop-down · การ์ดทักทายหน้าแรกมีภาพธีมไทยสีสดใส (วัดอรุณ เจดีย์ เรือหางยาว ดอกบัว) อ่านข้อความได้ชัด · เมื่อ login เป็น Admin เห็น**เฉพาะเมนูหลังบ้าน** (หน้า `/` พาไป `/admin`) · เมนู **การแจ้งเตือนของ Admin** `/admin/notifications` แสดงเรื่องที่ต้องดำเนินการแบบสด (ส่ง สตม. ไม่สำเร็จ, เลยกำหนด SLA, add-on ล้มเหลว, คืนเงินล้มเหลว, เอเจนซี่/พาร์ทเนอร์รออนุมัติ, ยอดพาร์ทเนอร์ที่ยังไม่จ่าย, ข้อผิดพลาด 24 ชม.) พร้อมตัวเลขบนกระดิ่ง · **กดการแจ้งเตือนแล้วระบบ mark ว่าอ่านแล้วทันที** (และตัวเลขบนกระดิ่งลดลง)
- **ติดตั้งเป็นแอป:** ปุ่ม "ติดตั้ง" ติดตั้งได้ในคลิกเดียวบน Chrome/Edge/Samsung (สาเหตุที่ปุ่มไม่ขึ้นเดิม: เบราว์เซอร์เสนอติดตั้งตั้งแต่โหลดหน้า แต่หน้า "บัญชี" เปิดทีหลังจึงพลาดสัญญาณ ตอนนี้เก็บไว้ตั้งแต่ต้น) · iPhone/iPad ทำปุ่มติดตั้งไม่ได้ (ข้อจำกัดของ Safari) จึงแสดงขั้นตอนแทน · ทดสอบในเบราว์เซอร์ด้วยสัญญาณจำลอง **ยังไม่ได้ลองติดตั้งจริงบนมือถือ**
- **รอบปรับแต่งหน้าแรก/Admin:** หน้า `/admin` ใช้การ์ด "สวัสดี คุณ…" แบบเดียวกับลูกค้า (ข้อความ "เฉพาะผู้ดูแลระบบเท่านั้น…") และไม่มีลิงก์ "กลับไปหน้าแรก" · การ์ด "สำหรับเอเจนซี่/พาร์ทเนอร์" อยู่หลัง "บัญชี" · **สีของการ์ดเกลี่ยอัตโนมัติ** (การ์ดที่ติดกันไม่ซ้ำสี, สีใกล้กันไม่อยู่ชิด; ทั้งลูกค้าและ Admin; มี unit test) · **แจ้งเตือนของ Admin**: กดรายการแล้วถือว่า "เห็นแล้ว" ตัวเลขบนกระดิ่งลด รายการยังอยู่จนกว่างานจะเสร็จ, มีปุ่ม "ทำเครื่องหมายว่าอ่านทั้งหมด", ถ้ามีเรื่องใหม่/จำนวนเพิ่มจะขึ้นเป็น "ยังไม่เห็น" อีกครั้ง · **Audit Trail ตั้งค่าได้** ที่ `/admin/audit`: ปิด/เปิดทั้งระบบ และ tick เลือกชนิดเหตุการณ์ที่เก็บ 12 กลุ่ม (ที่บันทึกเสมอ: การเพิ่ม/ถอด Admin และการเปลี่ยนการตั้งค่านี้) · Admin มีเมนู/การ์ด "บัญชี"
- **แก้บั๊ก:** หน้า `/apply` ล้มเมื่อถอดรหัสเลขพาสปอร์ตที่บันทึกไว้ไม่ได้ ("Unsupported state or unable to authenticate data" ใน `/admin/errors`) — ตอนนี้ไม่ล้มแล้ว ให้ผู้เดินทางกรอกเลขใหม่ · **สาเหตุที่น่าจะเป็น:** `DATA_ENCRYPTION_KEY` ใน Vercel ถูกเปลี่ยนหลังจากมีข้อมูลที่เข้ารหัสด้วยกุญแจเดิมแล้ว (ข้อมูลเดิมถอดรหัสไม่ได้) กรุณาอย่าเปลี่ยนกุญแจนี้อีกเมื่อมีข้อมูลจริง
- **Dashboard รายได้** `/admin/revenue`: แยกเป็น e-VOA (ค่าวีซ่า+ค่าบริการ) / ประกัน / ซิมและ eSIM / VIP / ความงามและสุขภาพ เลือกช่วง วันนี้-สัปดาห์นี้ (เริ่มวันจันทร์)-เดือนนี้-ปีนี้-กำหนดเอง (เวลาไทย) มีสรุป กราฟแท่ง รายการชำระเงิน และปุ่ม **Export CSV** ตามช่วงที่เลือก (บันทึกใน Audit ว่าใครส่งออก) · ตัวเลขคือเงินที่ผู้เดินทางจ่ายก่อนหักส่วนแบ่งพาร์ทเนอร์/ค่าธรรมเนียมบัตร นับตามวันที่ชำระ และหักการคืนเงินตามวันที่คืน
- **กฎอัตโนมัติ** `/admin/rules`: เตือนชำระเงิน · ปิดใบสมัครที่ไม่ชำระ (เก่าเกินกำหนดหรือเที่ยวบินลงแล้ว → "หมดอายุ" ใบสมัครที่ชำระแล้วไม่ถูกแตะ) · เตือนให้แก้ไข · เตือนเจ้าหน้าที่ใกล้/เลย SLA · ปุ่ม "รันเดี๋ยวนี้" · ส่งข้อความไม่ซ้ำ · แผนฟรีของ Vercel รัน cron วันละครั้ง
